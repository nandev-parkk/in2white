# Figma UI 정합성 수정

사용자가 점검 결과의 구현을 승인했다. 기존 기능은 유지하고 확인된 시각적 불일치를 수정한다.

- 공통 클래스 병합에서 글자 크기와 색상이 서로 제거되는 원인을 수정한다.
- 사이드바·카드·테이블·폼의 간격과 타이포그래피를 기존 디자인 토큰으로 맞춘다.
- 목록은 레이아웃을 유지하는 스켈레톤, 화이트보드는 헤더를 유지하는 중앙 스피너를 사용한다.
- 저장 완료 아이콘은 성공색, 연결 끊김은 위험색으로 표시한다. 내보내기는 더 보기 메뉴로 이동한다.
- API·권한·저장 및 오류 복구 계약은 변경하지 않는다. 검색·사이드바 크기 조절 등 기존 편의 기능을 유지한다.
- 워크스페이스 설정 신규 기능은 범위 밖이다. 폰트 교체나 신규 의존성 도입은 하지 않는다.
- 클래스 병합 회귀 테스트, 헤더 상태 테스트, 전체 테스트·린트·빌드 및 가능한 브라우저 검증을 수행한다.
