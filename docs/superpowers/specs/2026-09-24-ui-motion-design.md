# UI 모션 설계

## 목표

프로젝트 목록, 공통 모달, 화이트보드 참여자 표시가 사용자 입력과 협업 상태 변화에 짧고 자연스럽게 반응하도록 한다. 이미 설치된 `motion`과 `tw-animate-css`를 사용하며 새 의존성을 추가하지 않는다.

## 확정된 동작

- **프로젝트 카드:** 포인터를 올리면 카드가 최대 2px 올라오고, 누를 때 살짝 작아진다. 160ms 안팎의 짧은 ease-out을 사용하고 시스템의 모션 감소 설정에서는 이동·축소를 생략한다.
- **모달:** 공통 Radix overlay는 페이드 인·아웃하고, 콘텐츠는 페이드와 작은 크기 변화로 열고 닫는다. 현재 쓰는 `tw-animate-css`의 state 기반 CSS 애니메이션을 사용해 Radix의 포커스 관리와 닫힘 수명을 유지한다. 닫힘 애니메이션은 모션 감소 설정에서 생략한다.
- **참여자 아바타:** 새 참여자는 페이드와 작은 크기 변화로 나타나며, 나간 참여자는 사라진다. 남은 아바타의 위치 변화는 짧게 보정한다. 초기 화면의 기존 아바타에는 입장 애니메이션을 재생하지 않는다.
- **접근성:** Motion 애니메이션은 `useReducedMotion`으로 시스템 설정을 따른다. 기존 버튼, 대화상자 키보드 동작, 아바타 이름과 오른쪽 여백을 유지한다.

## 범위

- `frontend/src/features/project/ui/ProjectCard.tsx`
- `frontend/src/shared/ui/dialog.tsx`
- `frontend/src/shared/ui/presence-avatar-stack.tsx`
- 기존 화면과 테스트에서의 회귀 확인

페이지 전환, 카드 목록 순차 등장, Excalidraw 캔버스 도형 애니메이션은 포함하지 않는다. API, 권한, 저장 및 오류 계약은 바꾸지 않는다.

## 검증 계획

- 기존 동작과 접근성 계약을 확인하는 컴포넌트 회귀 테스트를 추가하거나 갱신한다.
- 카드 hover/press, 모달 열기/닫기, 참여자 추가/삭제를 브라우저에서 확인한다.
- 키보드로 모달을 열고 닫으며 포커스 복귀와 기존 조작이 유지되는지 확인한다.
- 모션 감소 설정에서 카드 이동·축소와 모달 state 애니메이션이 생략되는지 확인한다.
- 프로젝트 프런트엔드 lint와 production build를 실행한다.
