# 토스트 상태 색상 구현 계획

> **실행 방식:** `superpowers:executing-plans`로 아래 단계를 현재 작업 트리에서 순서대로 수행한다. 사용자의 요청 전에는 커밋·푸시·PR을 만들지 않는다.

**목표:** 성공·오류·정보·경고 토스트의 아이콘, 1px 테두리, 제목·설명 색상을 맞추고 피그마의 기존 컴포넌트에도 반영한다.

**설계:** [토스트 상태 색상 디자인](../specs/2026-09-25-toast-status-colors-design.md)을 따른다. 기존 Sonner 유형별 스타일에 색상 클래스를 추가하고, 밝은 테마의 성공·정보·경고에만 대비를 확보한 토스트 전용 색상 변수를 사용한다. 피그마에는 같은 값의 변수를 만들고 기존 컴포넌트에 연결한다.

**기술:** React, Sonner, Tailwind CSS 4, Vitest, Figma Plugin API

## 변경 파일과 책임

- `frontend/src/app/styles/index.css`: 토스트 전용 색상 변수 세 개와 Tailwind 색상 연결
- `frontend/src/shared/ui/toast.tsx`: 네 유형의 아이콘·테두리·문구 색상 적용
- 이 문서: 실제 변경, 검증 결과, 후속 작업 기록
- 피그마 `in2white Design System`의 `Components > Toast` (`46:48`): 네 기존 컴포넌트의 색상 연결

- [x] `toast.tsx`의 네 유형에 1px 테두리와 전경색을 적용하고, 아이콘에도 같은 색을 적용한다. 일반·로딩 토스트와 기존 배경은 유지한다.

- 실제 변경 내용: `index.css`에 토스트 전용 색상 세 개와 Tailwind 연결을 추가하고, `toast.tsx`에서 네 유형의 1px 테두리·문구·아이콘 색상을 맞췄다. 피그마 `Color` 컬렉션에 `color/toast/success`, `color/toast/info`, `color/toast/warning` 변수를 추가하고 기존 토스트 컴포넌트 네 개의 테두리·레이블·아이콘에 연결했다. 기존 화면의 성공 토스트 인스턴스(`220:4695`)가 수정된 원본을 참조하는 것도 확인했다.
