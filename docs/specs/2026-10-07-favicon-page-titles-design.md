# 파비콘과 브라우저 탭 제목

- 목표: 사용자·어드민에 기존 로고 파비콘과 페이지별 제목을 적용한다.
- 승인 규칙: client는 `in2white | 페이지명`, admin은 `in2white admin | 페이지명`이다.
- 상세 화면은 상위 경로 없이 실제 프로젝트·화이트보드·사용자·워크스페이스 이름만 표시한다. 이름 변경도 반영한다.
- 로딩·조회 실패 시 해당 상세 페이지의 기본 이름을 사용한다. 인증·워크스페이스 확인 중 아직 페이지 내용이 없으면 앱 기본 제목을 사용한다.
- 기존 84×84 PNG 로고 심볼을 두 앱의 `favicon.png`로 재사용한다. 추가 이미지 생성·의존성은 필요 없다.
- 각 페이지의 기존 데이터와 공용 제목 훅을 사용한다. 제목용 API 요청, 권한·데이터 계약 변경은 없다.
- 페이지 전환·동일 화면의 이름 변경·로딩·오류·해제를 테스트하고 두 앱 및 공용 UI의 테스트·린트·빌드를 검증한다.
