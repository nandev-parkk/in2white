# iPad 모달·카드 탐색·화이트보드 캔버스 설계

## 목표

iPad에서 소프트 키보드가 모달과 Excalidraw 캔버스 레이아웃을 깨뜨리지 않게 하고, 프로젝트와 화이트보드 카드를 카드 어느 곳에서든 열 수 있게 한다.

## 사용자 동작

- 터치 기기에서 모달을 열면 입력란에 자동 포커스하지 않고 모달 자체에 포커스한다. 데스크톱의 입력 자동 포커스는 유지한다.
- 키보드가 열린 동안 모달은 Visual Viewport 위쪽에 배치되고 높이는 표시 영역 안에 제한된다. 키보드가 닫히면 중앙 정렬로 돌아간다.
- 프로젝트·화이트보드 카드는 전체 영역을 눌러 상세 화면을 연다. 기존 메뉴는 독립적으로 계속 조작할 수 있다.
- iPad 키보드가 열리거나 닫히면 Excalidraw 컨테이너 높이와 캔버스 레이아웃을 갱신한다.

## 변경 범위

- 공통 Dialog의 포커스 및 Visual Viewport 반응
- 프로젝트·화이트보드 카드의 탐색 버튼 영역과 메뉴 쌓임 순서
- 화이트보드 캔버스의 Visual Viewport·창 이벤트 처리
- 관련 회귀 테스트와 문제 해결 문서

서버 API, 저장 데이터, 권한 계약은 바뀌지 않는다. Visual Viewport가 없는 브라우저는 현재 창 높이와 기존 CSS 높이를 사용한다.

## 접근성

탐색은 기존 제목 버튼 하나로 제공해 키보드 포커스와 접근 가능한 이름을 유지한다. 메뉴는 탐색 버튼보다 위에 표시해 메뉴 항목을 직접 조작할 수 있게 한다. 터치 모달은 모달 컨테이너를 포커스 대상으로 사용한다.

## 완료 조건

- 터치 모달은 입력란 자동 포커스를 피하고, 키보드가 열린 상태에서 콘텐츠와 버튼에 접근할 수 있다.
- 데스크톱 입력 자동 포커스와 모달 닫기 포커스 복귀가 유지된다.
- 프로젝트·화이트보드 카드의 전체 클릭 영역과 메뉴 조작을 회귀 테스트로 확인한다.
- Visual Viewport 크기 변경 시 캔버스 높이와 Excalidraw 갱신을 확인한다.
