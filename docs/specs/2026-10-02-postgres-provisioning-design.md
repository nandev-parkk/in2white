# 기존 PostgreSQL 프로비저닝 설계

## 목표

기존 PostgreSQL 서버에 in2white 전용 로그인 역할과 데이터베이스를 한 번 생성하는 실행 명령을 제공한다. PostgreSQL 컨테이너는 추가하지 않는다.

## 실행 계약

- 앱용 `DATABASE_URL`에서 DB 이름·역할 이름·비밀번호를 읽는다.
- 일회성 명령에만 전달하는 `POSTGRES_ADMIN_URL`로 기존 PostgreSQL에 연결한다. 관리자 URL은 평상시 백엔드 서비스 환경에 넣지 않는다.
- 역할·DB가 없을 때만 생성한다. 이미 있는 DB의 소유자가 앱 역할과 다르면 실패하고, 기존 역할의 비밀번호는 변경하지 않는다.
- 마지막에 앱 URL로 접속해 실제 사용 가능 여부를 확인한다. 마이그레이션은 그다음 기존 `drizzle-kit migrate` 명령으로 실행한다.
- 식별자·비밀번호는 PostgreSQL의 `format('%I', ...)`·`format('%L', ...)`로 안전하게 인용한다. 실패 로그에는 접속 URL이나 비밀번호를 출력하지 않는다.

## 배포 순서

백엔드 이미지 빌드 → 일회성 프로비저닝 명령 → 스키마 마이그레이션 → 서비스 시작. 업데이트에서는 프로비저닝 명령을 다시 실행해도 기존 DB·역할을 보존한다.
